# Limitations

Forward-only post-norm block with ReLU and no dropout. No gradients, optimizer, tokenization, training, next-token head, generation, cross-attention, KV cache, GPU or real text evaluation. Key padding does not zero queries; fully masked rows return zero attention, not necessarily zero residual outputs. The PyTorch MultiheadAttention and TransformerEncoderLayer comparison uses shared weights and 2D masks with no fully masked rows; SDPA is the reference for fully masked attention. All data are synthetic float64 arrays and three fixed seeds. Agreement does not establish arbitrary-input robustness or generalization. Weight element counts exclude Q/K/V, projections, other intermediates and allocator overhead. Not latency or memory measurements. No Docker or lint verification. Not peer-reviewed.
